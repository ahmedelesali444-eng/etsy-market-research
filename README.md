# ADAM Market Research (personal)

A personal, read-only research tool built on the Etsy Open API v3.

## What it does
- Pulls public active-listing, shop and review data for a small set of keywords
  about digital planners and content-creation templates
- Analyzes the data locally (price ranges, favorites, review themes)
  to inform my own product decisions as an Etsy seller

## What it does NOT do
- No write actions of any kind
- No scraping of Etsy web pages; official API only
- No redistribution, resale or public display of Etsy data
- No other users; personal use only

## Usage
Low request volume, cached responses, within Etsy's rate limits.
API credentials are stored locally and never committed to this repo.
